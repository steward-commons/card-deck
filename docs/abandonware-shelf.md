# Blockbuster shelf (DOS-era, scouted 2026-11-18)

A browsable wall of notable DOS-era and early-Windows titles, in the spirit of walking a Blockbuster aisle. Titles were discovered in part by browsing My Abandonware as a **catalog only**. This file is not a download source, and it does not link to abandonware files. Before anything is installed, rights get cross-checked: we use an official freeware or rights-holder giveaway, a live official or authorized server, or a store such as GOG or Steam. If a title is for sale, buy it with the owner's OK. No piracy.

Prices below were checked 2026-11-18 (America/Chicago) when a live store page was opened. Sale prices can end anytime.

## How to read the tags

| Tag | Meaning |
|---|---|
| **Free-official** | Official freeware, a rights-holder giveaway, or a free official / authorized server. Can start anytime. |
| **Buy on GOG/Steam** | Sold by a current store or official service. Needs the owner's OK because it costs money (unless already owned). |
| **Check rights first** | No verified official freeware, authorized server, or live store listing was found on this pass. Do not download it from catalog or "abandonware" sites. |

Store and official links are included only when the URL was checked live and did not 404 or bounce to a generic store homepage.
